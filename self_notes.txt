FUNCTION OVERLOADING 

allows us to define multiple functions with the same name but with different parameters , so the same function name can perform different tasks depending on the values and types of arguments passed

Avoids name conflicts and unnecessary function names 
makes the code easy to understand and makeing user friendly as the same meaningful function name is used for diff types of inputs

asssume that u have to add 2 integers it is easy to make a function for that 

int add2(int a , int b)
{
  return a+b;
}

now assume that u also need a function that adds 3 integers , once method is to create another function with diff name

int add3(int a , int b , int c)
{
  return a+b+c
}


but it may be diffi ult for u to understand the behaviour of funtion because its name differs , moreover it is very possible to forget about other function

this is where function overloading comes into play , it allows us to create both of the functions with same name as shown 

#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}
// Same function with different arguments
int add(int a, int b, int c) {
    return a + b + c;
}

int main() {
    int a = 5, b =7, c = 11;
    // Add function to add two numbers
    cout << add(a, b) << endl;
    // Add function to add three numbers
    cout << add(a, b, c);
    return 0;
}


DIFFERENT WAYS OF FUNCTION OVERLOADING

3 ways of function overloading are:

by having diff number of parameters 
by havinf diff types of parametersby having both diff number and and types of parameters

1. Different number of parameters

we can overload a function by changing the number of parameters that it accepts

2. Different types of parameters

we can also chnage the type of data , of parameters while keeping the same function name in function overloading

3. Different Number and types of parameters

functions can also be overloaded by changing both the number and types of parameters


There are functions that cannot be overloaded

as function overloading is primarily based on the function name and the types of number of its parameters 
there could be cases where c++ compiler cannot differenciate between functions and thus cannot be overloaded

1. member function declaration with diff access specifier but same name and same parameter type list cannot be overloaded

2. functions with parameter declaration that differ only in a pointer * versus and array [];

3. function with same parameter but diff passing methods

4.Function with same parameter but diff volatile type specifier

PARAMETER PASSING TECHNIQUES 

data is passed to functions during a call to perform operations , this data is know as parameters or arguments and c++ supports various parameter passing tech 

formal parameters : variables used in parameter list of a function as placeholders  , also called only parameters

actual parameters : expressions or values passed in during a function call , also called arguments 

PASS BY value

a variables value is copied and then passed to the function as the result any changes to the parameter inside the function will not affect the variables original value in the caller
the method is simple easy to implement but it is not preferred for large size of data structures as it involves copyint the value 


PASS BY REFERENCE 

In pass by reference method instead of passing the value of the argument , we pass the refernece of an argument to the function , this allows the function to change the value of the original argument , this is useful when u have to pass large size data  

PASS BY POINTER 

pass by pointer is very similar to the pass by reference method , the only difference is that we pass the raw address of the argument as the parameter to the function instead of reference

DEFAULT ARGUMETS IN C++

A default argument is a value provided for a parameter in a function declaration that is automatically assigned by the compiler if no valye is provided for those parameters in the function call 

default arguments must be present on the right side only , once a default argument is provided , all the argument is provided, all the arguments to its right must also be defaults

it is recommended to specify them in function declaration (usually in the header)

Syntx of default arguments

a default argument is defined by assigning a value to a function parameter in it declaration

return_type name (p1=v1 , p2=v2 , ....);

v1,v2 are default values for the parameters  p1 , p2 ...respectiverly

RULES TO FOLLOW 

1. default values should be specified in function declarartion
the default values for parameters should be specified in the function declaration . if a function is declared and defined separately , the default values must be in the declaration , not in definition 

void func(int x =10);

void func(int x){
  cout <<"value :"
<<x<<endl;
}

2. Default Arguments cannot be modified 

once default arguments are defined in the declaration they cannot be modified in the function definition , if u try to change the default value in the definition , it will result in a compilation error 

void f (int a =10);
this definition will throw an error

void f(int a =22)
{
  statements
}

3. Default arguments must be provided from right to left 

in a function with multiple parameters , default valyes must be provided from the rightmost parameter to the left , it means that if a parameter has a default arguments all parameters to its right muct have default values 

valid 
void func(int x , int y =20)

invalid as y doesnt have a default value
void func(int x =10, int y);

4. Ambiguity in function overloading

if a function containing default arguments is overloaded , then we need to make sure it is not ambiguous to the compiler otherwise it will throw and error

valid 
void f(int a =10 , int b =20);

will throw error as the signature is same
void f(int a);

will also throw error 
void f (int a);

will also throw an error
void f (int a , int b)
