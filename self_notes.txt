DEFAULT ARGUMETS IN C++

A default argument is a value provided for a parameter in a function declaration that is automatically assigned by the compiler if no valye is provided for those parameters in the function call 

default arguments must be present on the right side only , once a default argument is provided , all the argument is provided, all the arguments to its right must also be defaults

it is recommended to specify them in function declaration (usually in the header)

Syntx of default arguments

a default argument is defined by assigning a value to a function parameter in it declaration

return_type name (p1=v1 , p2=v2 , ....);

v1,v2 are default values for the parameters  p1 , p2 ...respectiverly

1. default values should be specified in function declarartion

INLINE FUNCTION IN C++

A function for which the compiler may replace the function call with the functions code to reduce function call overhead 

the inline keyword is only a request to the compiler and the compiler may choose whether to inline the function 

inline functions are mainly useful for small frequently called functions where call overhead may matter 

they also allow a function definition to appear in multiple translation units , make them useful in header files 

INLINE FUNCTION WITH A LARGER FUNCTION 

THE INLINE KEYWORD DOES NOT GURANTEE THAT A FUNCTION WILL BE EXPANDED AT EVERY CALL , the compiler considers factors such as function size , ptimization settings , recursion and whether inlining is benefical 

Compiler decisions for inline functions 

the inline keyword does not force the compiler to inline a function 
the compiler may inline a function declared with inline 

the compiler may also inline a function that is not explicitly declared with inline

the compiler considers factors such as dunctions size , optimization level , call frequency , and vailable optimization opportunities

functions contanining loops , recursion or conditional statemets are not automatically excluded from inlining 


INLINE FUNCTIONS AND MULTIPLE DEFINITIONS 

The inline specifier also has an important role in the c++ One definition rule (ODR)

an inline function can have the same definition in multiple trasnlation units 

this makes inline functions suitable for definitions in header files included by multiple source files 

the definitons must satisfy the requirements of the c++ ODR

The inline keyword does not necessarilty mean that the function will be physically substituted every call 

example 
//math_utils.h 

inline int square(int n){
  return n*n;
}

the header can be included in multiple source files without causing a multiple source files withhout causing a multiple definition violation provided the inline definition satisfies the ODR requirements 

INLINE AND VIRTUAL FUNCTIONS

A virtusl function can be inlined when the compiler can determine the actual function being called , such as through devirtualization , therefore it is incorrect to say that virtual functions can never be inlined 

virtual dispatch normally selects the function at run time

if the compiler can determine the actual object type it may eliminate the virtual call 
after determining the target function the compiler may inline it 

thus virtual functions and inlining are not mutually exclusive

CONCATENATION OF STRINGS

Strings can be joined using the + operator or the append() function

MODIFYING A STRING

time complexity for push/pop is O(1) and o(n) for insert/erase 

SUBSTRING EXTRACTION 

The substr(pos,len) is used to extract a part of a tring , where pos means the starting position and len means how many chars you want to copy

this function creared a new string containing the selected portion, starting at pos and copying len chars 

time complexity of extraction is O(len).

SEARCHING IN A STRING

The find() function is used to search for a substring inside a string , if found it returns the index positioin where the substring starts if not it returns a special value 

time complexity to search is O(n*m) where n is the length of string and m is the substring length
